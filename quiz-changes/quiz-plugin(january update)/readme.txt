# Quiz Plugin

## Description
The **Quiz Plugin** is a custom-built WordPress plugin designed to create engaging quizzes with advanced features such as real-time answer checking, category-based bifurcation, and WooCommerce integration.

---

## Features
- **Category Bifurcation**: Organize quizzes by categories for easy navigation.
- **AJAX Registration**: Seamless user registration without page reloads.
- **Real-Time Answer Checking**: Instant feedback for answers.
- **Buzzers**: Audio alerts for correct and incorrect answers.
- **Result Display**: Shows quiz results immediately after completion.
- **WooCommerce Integration**:
  - Use coins or discounts for quiz attempts.
  - Encourage engagement through rewards.
- **Certification of Appreciation**: Generate certificates for participants upon successful completion.

---

## Installation
1. Upload the plugin to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.

---

## Usage
1. Navigate to the **Quiz Plugin Settings** in the admin panel.
2. Create and manage quizzes by selecting categories and adding questions.
3. Display quizzes on your website using the shortcode: `[quiz id="QUIZ_ID"]`.

---

## WooCommerce Integration
- Enable quiz purchase using WooCommerce coins or discounts.
- Configure rewards or discount settings in the WooCommerce panel.
