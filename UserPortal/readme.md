
# Abstract Submission & Approval Portal  

## Overview  
This portal facilitates the submission, review, and approval of abstracts while ensuring eligibility verification. It includes an automated approval process involving an **RC Convener** and **Secretary** before issuing a downloadable certificate.  

> **Note:** This portal requires the **Paid Memberships Pro (PMPro) plugin** for membership validation.  

## Features  

### 1. User Eligibility Check  
- Users must have at least **one valid RC membership**.  
- Users must have completed the **latest membership payment**.  
- If eligible, the **"Submit Abstract"** option becomes visible.  

### 2. Abstract Submission  
Users can submit abstracts with the following details:  
- **Author Name (Submitter)**  
- **Co-Author Name(s)** (Multiple can be added)  
- **Abstract Title**  
- **Abstract Description**  
- **Membership Selection**  
- **Submit Abstract** button  

### 3. Notification System  
- **Email to Submitter:** Confirms abstract submission.  
- **Email to RC Convener:** Notifies about a new abstract request.  

### 4. RC Convener Review Process  
After submission, the abstract enters the **"Pending for Review"** status. The RC Convener can:  
- **Approve:** Sends the abstract to the Secretary for final review.  
- **Edit:** Requests changes from the author via email.  
- **Reject:** Notifies the author of rejection.  
- **Keep Pending:** No immediate action is taken.  

### 5. Secretary’s Final Decision  
Once the RC Convener approves the abstract, the Secretary has two options:  
- **Approve:** Generates a certificate (PDF) and stores it in the author's account. The author is notified via email.  
- **Reject:** Notifies the author of rejection.  

### 6. Certificate & Document Handling  
- Approved abstracts will have a **PDF certificate** stored in the user’s account for download.  
- Abstracts can be downloaded in **DOC format** for review.  

## Required Plugin  
This portal requires the **Paid Memberships Pro (PMPro) plugin** to validate user membership before allowing abstract submission.  

## Installation & Setup  
1. Install & activate **Paid Memberships Pro (PMPro)**.  
2. Ensure users have a valid **RC membership** with completed payments.  
3. Configure abstract submission rules based on membership levels.  
4. Upload and activate the custom abstract submission plugin/theme files.  
5. Ensure email notifications are correctly configured.
